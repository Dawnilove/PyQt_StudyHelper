고치기 전

self.btnClear.clicked.connect(self.clear_all())

괄호를 붙이면 지금 바로 실행돼요. 함수 이름만 넘겨요.

고친 뒤

self.btnClear.clicked.connect(self.clear_all)
  • .ui에 없는 위젯 이름 (오타)
  • setupUi 빠뜨림
  • self. 빠뜨림

막히는 곳마다 도움이 있습니다

줄 해설
줄을 누르면 무엇을, 왜, 주의할 점을 인터넷 없이 설명합니다. 규칙은 170여 가지입니다.
에러 해설
F5로 실행합니다. 에러가 나면 쉬운 말로 풀고 그 줄로 이동합니다.
코드 대신 넣기
위젯을 우클릭하면 시그널 연결 코드와 함수 틀을 만듭니다.
.ui 편집
미리보기에서 위젯을 추가, 삭제하고 속성을 고칩니다. 되돌리기가 됩니다.
AI 해설
Gemini 무료 티어, Claude Code, 웹 AI, Ollama 중에서 고릅니다.
연습
저장할 때마다 채점되는 코드 과제 8개와 Designer 도전 모드가 있습니다.

Windows에 설치합니다

설치 파일

PyQtStudyHelper-Setup-1.6.0.exe를 받아 실행합니다. Python이 함께 들어 있습니다.

git과 가상환경

Python 3.10 이상이 필요합니다.

git clone https://github.com/Dawnilove/PyQt_StudyHelper.git
cd PyQt_StudyHelper
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python run.py
